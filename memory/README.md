# memory

Local, repo-scoped memory. Not chat history — **experience we want the next session to reuse**.

```
memory/profile.md     standing facts (short, curated)
memory/log/YYYY-MM.md append-only notes for that month
```

## Write a note

Add a dated bullet to this month's log:

```
## 2026-08-26
- 12-minute product demo: gist-first then 5 bullets beat a long outline.
```

If the same lesson appears twice, fold it into `profile.md` as one sentence.

## Do not

- Store secrets, cookies, or private transcripts.
- Duplicate a full summary here. Link the category file instead.
