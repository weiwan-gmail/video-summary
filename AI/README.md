# AI

Video summaries in this category: models, papers, product launches, research talks.

Organize by year: `AI/YYYY/YYYY-MM-DD-slug-transcript.md` plus a sibling `.summary.md`.

The `*-transcript.md` file is the **reading transcript**: content-segmented `### [MM:SS] …` sections with merged paragraphs, full spoken text retained — the same layout as handbook `## 全文原文`. Do not leave Whisper crumb lines (`[mm:ss-mm:ss]` every few seconds) as the published body.
